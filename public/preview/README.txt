Runtime assets for the WebGL preview (NOT redistributed — see licenses):

  live2dcubismcore.min.js
      Live2D Cubism Core, proprietary. Download it from the official
      Live2D site (https://www.live2d.com/) and place it in this folder;
      its license forbids redistributing it from this repository.

  model.moc3 + texture_00.png
      Any exported model you want to preview. The ones used during
      development derive from a third-party game asset and must not be
      redistributed.

model-preview.html expects all three files under these exact names.
